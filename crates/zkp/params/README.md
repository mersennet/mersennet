# Pinned ZK Parameter Artifacts

This directory holds binary artifacts that pin the in-Rust mirrors of
ZK primitives to a known parameter set. Each artifact is loaded at
process start via `include_bytes!` and decoded once.

| File | Used by | Purpose |
|---|---|---|
| `poseidon-bn254.bin` | `crates/zkp/src/poseidon.rs` | Pinned Aztec Poseidon-2 BN254 width-3 round constants + MDS matrix. |
| `sp1/state-transition.vk.hash` | SP1 host runner and release process | Pinned verifying-key hash for the checked-in `programs/state-transition` ELF build. |

## File format: `poseidon-bn254.bin`

```
byte 0       : magic 0xAE
byte 1       : version 0x01
byte 2       : width                  (= 3)
byte 3       : full_rounds            (= 8)
bytes 4..5   : partial_rounds (LE u16) (= 56)
bytes 6..N   : (full+partial)*width  × 32-byte LE Fr round constants
bytes N..end : width*width            × 32-byte LE Fr MDS matrix entries
```

Total length for the Aztec-BN254-W3 config: `6 + (192 + 9) * 32 = 6438`
bytes.

## File format: `sp1/state-transition.vk.hash`

Plain ASCII lowercase hex, exactly 64 nybbles, no `0x` prefix, with an
optional trailing newline.

## Regenerating the artifact

The artifact is generated by an `--ignored` test in
`crates/zkp/src/poseidon.rs`:

```bash
cargo test -p mersennet-zkp --lib poseidon::tests::dump_pinned_params_file -- --ignored --nocapture
```

That writes the file from the in-source parameter synthesis. On a
fresh checkout the file is committed empty so the workspace stays
buildable; the dump step populates it on demand.

## Swapping in the audited Aztec parameter set

1. Replace the bytes of `poseidon-bn254.bin` with the encoding of the
   audited Aztec Poseidon-2 BN254 round constants and MDS matrix
   (canonical 32-byte LE Fr per element, same header layout).
2. Re-run the unit tests:
   ```bash
   cargo test -p mersennet-zkp poseidon
   ```
3. `hashes_match_pinned` will pass automatically — it only asserts
   self-consistency and reduced-canonical-Fr outputs.
4. CODEOWNERS: any change to this directory requires
   `@PrimeNumbersLabs/zk` review (see `.github/CODEOWNERS`).
