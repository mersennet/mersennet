## 3. Vesting Schedule

All tokens purchased in this round are subject to the following vesting:

```
         VESTING TIMELINE
         
    TGE    6m     12m    18m    24m
     │      │      │      │      │
     │      │      │      │      │
     │◄─────┤      │      │      │
     │ CLIFF│      │      │      │
     │  (0%)│      │      │      │
     │      │◄─────┴──────┴──────┤
     │      │   LINEAR VESTING   │
     │      │   (100% over 18m)  │
     │      │                    │
     │   Unlock                Fully
     │   begins               vested
     │
     0%    0%    33%    67%   100%
```

| Parameter | Value |
|-----------|-------|
| **Cliff** | 6 months from TGE |
| **Vesting** | 18 months linear (monthly unlock after cliff) |
| **Total Vesting Period** | 24 months from TGE |
| **TGE Unlock** | 0% (no tokens at TGE) |
| **First Unlock** | Month 7 (~5.56% of allocation) |

### Vesting Comparison (Alignment with Team)

| Stakeholder | Cliff | Vesting | Total |
|-------------|-------|---------|-------|
| **Series A Investors** | 6 months | 18 months linear | 24 months |
| **Team & Contributors** | 12 months | 36 months linear | 48 months |
| **Foundation Reserve** | 12 months | 48 months linear | 60 months |
| **Ecosystem & Grants** | None | 60 months linear | 60 months |

Team vests longer than investors, ensuring alignment.
