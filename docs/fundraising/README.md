## How to Use This Suite

### Stage 1: Initial Outreach
- Send **One-Pager** as email attachment or teaser
- Use **Pitch Deck** for first meeting (10–15 min presentation)

### Stage 2: Follow-Up
- Share **Executive Summary** after positive first meeting
- Share **Investor FAQ** to preemptively address concerns

### Stage 3: Due Diligence
- Open **Investor Data Room** access
- Walk through **Financial Model** with interested parties

### Stage 4: Closing
- Negotiate using **Term Sheet Template** as starting point
- Reference **Investor FAQ** for common negotiation points
