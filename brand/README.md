# Mersennet Brand Kit

Generated from the official five-bar mark (11111₂ = 31 = 2⁵−1, a Mersenne
prime) in phosphor green `#7dff9b` on black. See
[docs.mersennet.com/resources/brand-assets](https://docs.mersennet.com/resources/brand-assets)
for usage guidelines.

## logo/

| File | Use |
|---|---|
| `logo.svg` / `favicon.svg` | Vector master + favicon tile |
| `logo-green-{1024,512,256,128}.png` | Transparent mark, dark backgrounds |
| `logo-white-1024.png` | Transparent mark, photos/colored backgrounds |
| `logo-black-1024.png` | Transparent mark, light backgrounds |
| `lockup-dark-1800x420.png` | Mark + wordmark, transparent, for dark surfaces |
| `lockup-light-1800x420.png` | Mark + wordmark, transparent, for light surfaces |
